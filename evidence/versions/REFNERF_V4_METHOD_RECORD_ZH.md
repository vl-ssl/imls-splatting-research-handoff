# IMLS-Splatting V4：不透明镜面反射表面重建方法记录

## 1. 研究目标与版本边界

本版本以原始 [SilenKZYoung/IMLS-Splatting](https://github.com/SilenKZYoung/IMLS-Splatting) 为几何表示和可微表面渲染基础，目标是提高 Ref-NeRF 数据集中不透明镜面物体的表面完整性、视角相关反射表达能力和最终新视角合成质量。

V4 是一个统一方法，不是从多个不同模型中按场景拼接最优指标。六个场景使用同一套反射网络、损失定义、网格提取与渲染代码；场景间只允许使用网格分辨率、法线平滑、外观微调步数和学习率等超参数差异。最终指标均来自 `output/<scene>_final_v4`。

## 2. 原始 IMLS 的主要问题

原始 IMLS-Splatting 用隐式移动最小二乘场提取网格，再以空间 MLP 和方向 MLP预测颜色。对漫反射或弱高光物体较稳定，但面对不透明镜面表面时存在三类耦合问题：

1. 镜面高频随视角快速变化，基础方向 MLP 容量和方向参数化不足时，会把外观误差传回点位置、尺度与法线，导致几何被错误更新。
2. 稀疏覆盖、低分辨率体素网格及重采样可能在局部形成错误符号或孤立空体素，经 Marching Cubes 放大为小孔、凹坑和破碎轮廓。
3. 网格法线带有局部高频噪声时，反射方向也随之抖动，镜面外观会出现纹理噪声；但强制换用 SDF 法线或过强平滑又会改变旧检查点所适配的法线分布并损伤细节。

此外，渲染器给出的是相机到表面的射线距离，而 Depth Anything V2 输出更接近逆深度。二者直接归一化并排会造成前后关系看似相反。

## 3. V4 的统一方法

### 3.1 稳定几何与外观解耦

V4 从已经完成法线/透明度预处理的 `_op` 检查点开始，不再让镜面外观误差无限制改变稳定几何。外观适配阶段可将点位置、尺度和法线学习率设为零，同时关闭上采样与重采样；反射网络的几何梯度用 `reflection_grad_scale` 控制。最终导出阶段所有学习率均为零，只重建和渲染选定检查点。

这样做的核心含义是：镜面反射属于表面外观，不应仅因高光位置变化就把一个封闭表面“推破”。

### 3.2 检查点兼容的反射残差网络

原始空间 MLP 和方向 MLP 的参数名、维度及基础路径被保留，使 `_op` 旧检查点可以直接加载。在其输出上增加三个零初始化、有幅度上限的残差分支：

- 普通方向残差：补充基础方向 MLP 未表达的视角相关颜色；
- 表面位置残差：输入真实表面坐标及 Fourier 编码，表达固定在不透明物体表面的涂层、条带或材料边界；
- 环境反射残差：输入归一化反射方向、六频 Fourier 编码和 `N·V`，表达镜面表面观察到的高频环境反射。

三个分支最后一层均为零初始化，并通过 `tanh` 和固定尺度限制幅度，因此加载旧检查点的初始 RGB 不发生突变。各分支拥有独立学习率，基础渲染网络也可冻结。

反射方向采用 `r = 2(-v·n)n + v` 的等价形式，其中视线与法线先归一化。该思路参考 Ref-NeRF 对反射方向的参数化，以及 NeRF 系列常用的 Fourier 编码；本项目的残差结构与代码为新增实现，并非复制第三方实现。

### 3.3 法线保留、混合与边缘感知平滑

V4 保留此前加入的法线 GT 读取、法线混合和法线损失，没有删除。渲染法线可以在 Marching Cubes 网格法线与 SDF 梯度法线之间按权重混合；`mesh_normal_weight=-1` 保留旧迭代调度，`[0,1]` 使用固定比例。

实验显示旧反射检查点已经适配网格法线，直接切换为 SDF 法线会导致明显分布偏移，因此最终 V4 使用纯网格法线 `mesh_normal_weight=1.0`。对 car、coffee、helmet、toaster 使用边缘感知的网格邻域平滑，只在相邻法线余弦超过阈值时平均，以压制同一光滑面内的噪声并保护锐边；ball 和 teapot 关闭该平滑，避免球面过度处理和茶壶细节损失。

另外提供离线点法线修复工具：以 KNN 或体素邻域估计局部一致方向，只强修复可信邻域内的角度离群点；遇到可能包含相反表面片的低一致性邻域会跳过，以免把薄结构两侧错误平均。

### 3.4 表面完整性修复

V4 在 Marching Cubes 前后加入可选且默认关闭的修复模块：

- 覆盖空洞填充：只插值被足够多已覆盖邻居包围的空体素，同时插值 SDF 与特征；
- SDF 闭运算和轻度三维平滑：抑制亚体素级正值凹陷；
- 小连通分量过滤：去除小于面数或主分量比例阈值的浮游网格；
- 边缘感知网格法线平滑：降低平滑面法线抖动。

这些开关默认均为零，旧检查点保持原始渲染行为。V4 最终采用不重采样的稳定检查点：ball 使用 `80³` 网格以匹配其稳定点尺度，其余场景使用 `256³`；最终渲染统一启用 `SSAA=2`。SSAA 路径也被修复为先按倍率栅格化，再统一下采样图像、位置、法线、透明度、深度与材质图。

### 3.5 损失设计

训练的基础图像损失仍为 L1 与 SSIM 的加权组合，并增加以下可选项：

- 前景透明度 L1 损失：约束渲染 alpha 与数据集 alpha mask；
- 法线损失：对有效前景内的单位法线使用角度误差和鲁棒向量误差；
- LPIPS：按指定间隔在低分辨率图像上计算，减少显存和时间开销；
- 深度相关损失：用 Pearson 相关约束尺度不确定的单目伪深度。

3DGS 前置初始化另加入透明度正则，使高斯透明度趋于稀疏和稳定，并把 densification 起始步提前到 100。

最终 V4 不使用深度监督，即 `lambda_depth=0`。原因是 Depth Anything V2 是单目相对逆深度，尺度与 IMLS 射线深度并不一致，已有实验没有证明其能稳定改善几何。深度模块保留为可选消融和最终可视化，不参与当前最终结果。

### 3.6 最终导出和评估

最终导出按相机 UID 排序，保存全部可用训练和测试视角：

- RGB 渲染图和对应 GT；
- 左侧预测法线、右侧法线 GT 的组合图；
- 左侧预测逆深度、右侧 Depth Anything V2 的组合图。

如果某视角没有法线 GT、深度模型加载失败或缺少对应图，则只跳过该类组合图，不中断 RGB 导出。预测射线深度先取倒数，再与 Depth Anything 的输出分别按前景 1%–99% 分位归一化，解决深度明暗极性相反的问题。

评估统一在 200 个测试视角上计算 SSIM、PSNR 和 VGG-LPIPS；LPIPS 网络只初始化一次。对比脚本生成原始 IMLS、`_op`、统一 V4 和 GT 的同视角拼图，同时输出 CSV/JSON 指标表。

## 4. 最终采用的 V4 检查点与渲染超参数

| 场景 | 最终输入检查点 | 网格 | 网格法线平滑 |
|---|---|---:|---|
| ball | `ball_v4_grid80_tune3/iteration_500` | 80³ | 关闭 |
| car | `car_v4_appearance2/iteration_3000` | 256³ | 0.25 × 2 次，阈值 0.7 |
| coffee | `coffee_v4_appearance1/iteration_1500` | 256³ | 0.25 × 2 次，阈值 0.7 |
| helmet | `helmet_v4_appearance1/iteration_1500` | 256³ | 0.25 × 2 次，阈值 0.7 |
| teapot | `teapot_op/iteration_20000` | 256³ | 关闭 |
| toaster | `toaster_v4_reflection1/iteration_2000` | 256³ | 0.25 × 2 次，阈值 0.7 |

这里的选择属于同一模型下的检查点和超参数选择。最终导出统一使用纯网格法线、SSAA=2、关闭几何增删并冻结全部参数。

## 5. 最终结果与当前边界

| 场景 | SSIM ↑ | PSNR ↑ | LPIPS ↓ |
|---|---:|---:|---:|
| ball | 0.9514 | 28.963 | 0.1509 |
| car | 0.9077 | 20.175 | 0.0853 |
| coffee | 0.9616 | 26.963 | 0.1050 |
| helmet | 0.9481 | 27.808 | 0.0872 |
| teapot | 0.9959 | 42.612 | 0.0091 |
| toaster | 0.8802 | 20.348 | 0.1450 |
| **六场景平均** | **0.9408** | **27.811** | **0.0971** |

相对 `_op`，六场景平均 SSIM 提升 0.0111、PSNR 提升 1.033 dB、LPIPS 降低 0.0162，且 ball 的代表视角不再出现法线凹坑和渲染破洞。预设初期目标 0.95 / 28.5 / 0.09 尚未同时达到，当前差距分别为 0.0092、0.689 dB 和 0.0071，不能记为达标。

目前最值得继续研究的是 car/toaster 的外观容量与 coffee 的底层几何高频起伏。法线平滑只能抑制反射噪声，不能替代更可靠的几何约束；下一阶段应优先设计不依赖单目尺度、又不会把镜面纹理写进几何的多视图表面一致性约束。

## 6. 参考与原创性说明

- 基础 IMLS 表面表示、Marching Cubes 和原始渲染网络来自 SilenKZYoung/IMLS-Splatting。
- 反射方向参数化参考 Ref-NeRF；方向/位置 Fourier 编码属于 NeRF 系列通用思想。
- 单目深度来自 Depth Anything V2，本版本只将其用于可选损失与最终诊断图。
- 零初始化多分支残差、外观/几何解耦、局部覆盖修复、边缘感知法线平滑、最终全视角导出均为本项目针对不透明镜面表面重建加入的实现。
