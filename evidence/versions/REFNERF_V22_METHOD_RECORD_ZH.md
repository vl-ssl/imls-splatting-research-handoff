# IMLS-Splatting不透明镜面表面重建：累计方法记录（原始版至V39实验）

**2026-09-28帧身份勘误：**第22节发现训练相机随机打乱后按运行UID导出，离线投影工具却按原始metadata顺序读取。此前依赖该配对的V16–V27、V36–V37训练视角补点/筛点/剔除证据存在错配风险，其“多视角第一表面验证正确”的解释作废，不能据此评价算法机制；已保存的RGB/法线数值仍是实际生成输出的测量。V32直接训练使用成对相机对象，测试相机未随机打乱，当前证据未发现此问题影响V32测试RGB配对。以下历史记录保留供追溯，应优先阅读第22节的修正。

更新日期：2026-09-28。本记录面向论文撰写与后续方法设计，描述相对原始IMLS-Splatting的累计方法变化。代码级位置见`REFNERF_V22_CODE_CHANGE_RECORD_ZH.md`。所有“候选/计划”与“已验证”严格区分；不同版本、不同场景的最优指标不得拼成一个方法的结果。

## 1. 任务与评估约束

目标是对Ref-NeRF六个不透明镜面物体（ball、car、coffee、helmet、teapot、toaster）恢复连续、完整且法线可靠的实体表面，同时提高随视角变化的镜面倒影。最终方法必须六场景使用同一算法；允许自动尺度规则，但禁止按场景挑选不同版本结果。阶段目标是六场景等权平均SSIM≥0.96、PSNR≥29.0、LPIPS≤0.08，并同时检查逐场景孔洞、轮廓、分层、原始法线及倒影轮廓。

训练使用Ref-NeRF提供的法线和alpha属于额外监督，对比仅使用RGB的方法时必须披露。测试RGB/GT法线不作为训练损失或补点筛选输入；但开发过程中反复查看测试图和指标指导方法迭代，不能声称它们是从未用于模型选择的盲测集。严谨论文评价应另设开发验证集并保留独立最终测试协议。Depth Anything是相对逆深度诊断，不是几何GT。

## 2. 原始方法及前置初始化修改

原始IMLS-Splatting将点位置、点法线和核尺度累积成隐式移动最小二乘场，Marching Cubes提取网格，再由空间/方向MLP渲染。强镜面RGB容易与几何方向混淆；初始化点在轮廓处缺失时，后续仅靠表面损失难以生成新的可靠支撑。

前置3DGS曾加入名为“透明度损失”的`0.01*mean(opacity²)`并提前致密化。2026-09-22代码审查确认该正则在单独作用时降低点opacity，并不是前景累积alpha监督。它是否造成op2缺边仍需G0严格对照；原始IMLS的car也有类似车端缺失，因此不能将问题全部归因于此项。

## 3. V2–V6：法线、深度与统一反射外观

- 保留并增强训练GT法线监督，混合点法线与最终SDF梯度法线；不删除法线分支。
- 接入Depth Anything相对逆深度和Ref-NeRF视差诊断。多轮实验表明深度项没有稳定改善，正式配置通常令其权重为0，但保留接口与最终全视角对照。
- 增加方向残差、位置条件残差、环境方向MLP、材料条件方向贴图，以及V6直接球面RGB反射贴图和表面门控。几何固定后重拟合反射，避免RGB高光直接拖动实体表面。
- V6是目前本地可核对的完整六场景参考：平均SSIM 0.941671、PSNR 27.940088、LPIPS 0.096426。脚本对不同场景沿用V4的不同网格/法线平滑配置，因此应称“统一反射方法、场景配置有历史差异”，而非所有超参数完全相同。

V5的方向材料分解与Ref-GS的“方向—几何/材料分解”概念相近，但为本项目独立实现，未复制其代码。V6直接贴图属于本项目迭代，不宣称物理BRDF。

## 4. V7–V12：反射—几何解耦与表面连续性

V7把训练分为几何阶段和固定几何的外观阶段。几何阶段关闭RGB，增加soft-IoU、缺失前景召回、轮廓带、多尺度mask、GT法线连续性、点锚定和切向位移约束；外观阶段只优化表面特征和反射模块。相机Z深度统一了Ref-NeRF视差定义。

V8真实视差、V9点域双边投影、V11最差法线CVaR、V12窄带SDF Taubin扩散均未稳定优于参考，保留为消融。V10在Marching Cubes网格上做法线感知的弱Taubin映射，并在该映射中回传轮廓/法线损失；car和coffee两场景小幅改善，但coffee托盘分层、car首尾缺失仍存在。V10只验证了这两个场景，不能替代六场景V6结果。

## 5. V13–V21：镜面细节与缺失支撑实验

V13提高方向贴图分辨率，V14增加只用于反射方向的切向微法线；coffee提升都小于0.006dB，说明仅叠加小残差不足以解决倒影轮廓。V15释放轮廓损失仍不能创造缺失支撑。

V16用训练alpha视觉外壳和多视角缺失证据补充边界点，car轮廓明显恢复，但coffee凹结构不稳定；V17/V18几何校正和外观重拟合未形成跨场景统一收益。V19用IMLS支持度做窄带正则，收益不足。V20给辅助点置信度，V21再用原始点支持门控；coffee完成过探针，car没有完整V21结果，不能写成统一升级。

2026-09-22审计发现V20/V21还有实现混杂：原始点和辅助点分两次调用CUDA splatter，会改变旧核的分块拒绝行为，不只是改变置信度。因此旧V20/V21结果保留作探索证据，不用于证明严格的逐点加权IMLS。

## 6. V22-G：IMLS数值一致性与真实几何缓冲

### 6.1 已验证的CUDA问题

旧CUDA将每个体素的点列表按32点分块，并在每个分块内要求至少两个有效点才提交贡献。这使隐式场依赖点排列；反向核又按全体点求导，与前向拒绝不一致。归一化核的线程数还对`resolution³/256`向下取整，非整除分辨率的尾体素不归一化。

服务器RTX 4090实测：17³尾体素特征误差0.1974；33点反转顺序造成0.03125差异；被前向丢弃的最后分块，反向梯度0.03125而有限差分为0。

V22-G保留“至少两个点支撑”的原始意图，但把计数改为同一体素的全局原子计数，再统一归一化或置零；归一化线程向上取整并加入越界检查。修复后尾体素误差0、顺序差0，反向梯度0.0303030、有限差分0.0302941，误差约`8.97e-6`。旧/新二进制及源码分别留档。

直接用修复核重渲染旧V10检查点没有提升：car为0.911317/20.6151/0.080138，coffee为0.959448/27.1671/0.105987。原因是旧检查点已经适配旧数值场；V22-G是正确性基础，需要在新核上重新拟合，不能将直接换核结果称为最终版本。

### 6.2 原始法线、alpha和深度

旧路径保存`alpha*(n+1)/2`后又用`2x-1`恢复法线。alpha=0.5且真实法线为(0,0,1)时，会产生90度方向错误。V22将世界法线与alpha独立保存，SSAA后重新单位化，法线损失只在GT前景与可靠预测覆盖的交集计算；缺失区域由独立轮廓损失负责。最终全视角另存未量化的法线、alpha和camera-Z。

深度显示不再对camera-Z取绝对值；负值/非有限值保留为诊断错误。Depth Anything与预测逆深度继续各自可视化，但明确仅比较相对结构。

## 7. V22-R：粗糙度感知的方向反射候选

V22-R针对V13/V14“只增加分辨率或微法线但倒影仍模糊”的问题，增加可关闭的粗糙度方向因子分支：

1. 在反射方向上查询周期球面特征金字塔；表面特征预测连续粗糙度，以连续LOD控制方向带宽。
2. 表面材料特征产生RGB×方向通道系数，与方向特征做乘积聚合，再通过有界门控作为旧渲染器的反射残差。
3. 材料读出严格零初始化，旧检查点启用分支前RGB逐像素不变；服务器CUDA测试最大差为0，材料参数梯度非零。
4. 几何、原法线和旧反射模块先冻结，只训练V22-R分支；确认固定几何收益后才允许统一小学习率联合精修。

该设计明确参考[Ref-GS](https://arxiv.org/html/2412.00905v2)的Sph-Mip粗糙度方向表示和方向—表面因子化，以及[Ref-NeRF](https://dorverbin.github.io/refnerf/)的粗糙度相关方向编码思想；实现为本项目独立PyTorch代码，没有复制第三方源码。当前金字塔是平均池化近似，不能称为物理GGX预滤波或完整BRDF。

## 8. V22实验结果与采纳结论

修复核上统一300步几何精修后，car的IoU/缺失前景/原始法线平均角误差为`0.947459 / 3.9825% / 12.5841°`，coffee为`0.984446 / 0.3558% / 10.4517°`。两场景都优于同口径的旧V10探针，因此V22-G作为数值正确性和法线评估基础被保留。

在同一几何和2500步预算下，旧反射头控制组与V22-R结果为：

|Scene|旧反射头控制组 SSIM / PSNR / LPIPS|V22-R粗糙度因子分支|相对控制组|
|---|---|---|---|
|car|0.911392 / 20.61750 / 0.080056|0.911713 / 20.63365 / 0.078553|三项均改善；+0.01615 dB，LPIPS -0.001503|
|coffee|0.959932 / 27.19560 / 0.104731|0.960156 / 27.29599 / 0.104075|三项均改善；+0.10039 dB，LPIPS -0.000655|

相对旧V10，V22-R的car三项均小幅改善；coffee的PSNR高0.01944 dB，但SSIM低0.000113、LPIPS差0.000716。因此它证明了粗糙度方向因子化在IMLS表面上可训练且有统一增益，但还不是明显超越V10的最终版本。

代表视角目视显示：car前后端大面积缺失未修复，coffee托盘仍存在层状法线噪声，新旧反射头之间的倒影轮廓肉眼差异很小。这些结构问题不能靠继续增加外观残差解决，下一阶段改为“训练视角可见性验证的缺失支撑+多层错误支撑抑制”。V22归档为值得保留的数值修复/反射消融版本，不扩展为六场景最终结果。

V22-R明确参考Ref-GS的Sph-Mip与方向因子化概念；与3DGS-DR的延迟像素反射目标相近，但未复制其正常传播实现；本轮未引入GS-ROR²的双向GS-SDF训练或重照明管线。全部V22-R代码均在本项目中独立实现。

## 9. V23–V25：训练视角验证的不透明第一表面支撑

car首尾缺失说明原点集在轮廓处没有足够IMLS支撑；coffee多层托盘又说明直接加入视觉外壳会把遮挡后方或错误深度的点变成伪表面。针对不透明镜面物体，V23–V25将“该点是否得到训练视角第一表面证据”作为加入条件，而不是从高光RGB边缘猜测几何。

V23把V16产生的全部训练mask视觉外壳点直接并入V22。car的轮廓IoU从0.947459提高到0.958158、缺失前景降至2.6638%，但coffee法线误差升到11.4907°且RGB三项下降，因此统一方法被否决。V23大结果及其旧日志、诊断包已在结论写入本文后清理；脚本仍保留用于消融，不能作为最终版本。

V24对每个候选点统计：训练GT前景中当前模型缺失的视角数、与GT法线一致的缺失视角数、和当前camera-Z第一表面接近的视角数、以及候选点错误挡在可信第一表面之前的冲突数；同时限制其到原点集的距离。固定冲突上限12时，统一规则为car接纳368点、coffee接纳0点。car几何IoU/缺失/伪前景/法线平均角误差为`0.952824 / 3.4419% / 1.3298% / 12.2261°`，coffee保持V22不变。相同2500步V22-R外观训练后，car为`0.911973 / 20.88964 / 0.077945`，coffee为`0.960156 / 27.29599 / 0.104074`。代表视角确认车端有小幅真实补全，但尚未恢复完整封闭轮廓。

V25进一步把冲突预算写成统一证据函数：`front_conflicts <= max(12, 3*missing_views + near_views)`。这允许具有更强多视角缺失证据的car候选通过，同时仍拒绝coffee中遮挡冲突远高于缺失证据的候选；不是按场景手工切换模型。V25为car接纳656点、coffee接纳0点。直接探针中car几何IoU为0.955228，缺失前景3.2079%，伪前景1.3195%，法线平均角误差11.7282°；coffee与V22相同。

相同2500步V22-R外观训练后，V25统一结果为：car `0.912367 / 21.02768 / 0.077555`，coffee `0.960156 / 27.29600 / 0.104075`（SSIM / PSNR / LPIPS）。相对V24，car三项继续改善，PSNR约+0.138 dB；相对V22，car约+0.001SSIM、+0.394dB、LPIPS -0.000998，而coffee数值保持一致。代表视角显示车头/车尾补回更多真实实体面积，但离GT封闭轮廓仍有明显差距，倒影锐度也未出现质变。V25因此归档为“值得保留的轮廓支撑阶段版本”，不是达到0.96/29.0/0.08目标的最终版本，也没有扩展成六场景结论。

V24/V25第一表面证据筛选为本项目独立实现。它与GS-ROR²以显式GS和隐式SDF互相引导、以及3DGS-DR在像素空间延迟计算反射的总体目标有关，但没有复制两者的双向训练、法线传播或源码。V22-R继续明确参考Ref-GS的方向因子化与粗糙度多尺度表示。

## 10. V26–V28否决实验：伪支撑剔除与表面连续化

V24/V25只补缺边，不能移除coffee托盘已有的浮层。V26基于不透明物体约束：真实表面点在环绕训练视角中应至少一次接近当前第一表面；若一个点从未接近第一表面，却多次落在可信表面之前或GT背景内，则它可能是由镜面纹理误导初始化产生的幽灵支撑。工具只使用训练alpha、V22原始camera-Z和训练GT法线，禁止读取测试视角和RGB。

V26使用“前置冲突或背景冲突”规则，删除car 21291/194024点、coffee 17627/378849点。car降至`0.898428 / 20.34643 / 0.094761`，coffee降至`0.955265 / 26.64157 / 0.114325`；几何指标也退化，说明大量不直接成为第一表面的内部/背面点仍对IMLS场连续性有用，V26否决。

V27把规则收紧为前置与背景冲突必须同时很强，只删除car 329点、coffee 2096点。car为`0.902571 / 20.78099 / 0.088674`，coffee为`0.956939 / 27.07544 / 0.110703`，相对各自V25直接探针仍下降，法线也未改善，因此V27否决。结论是：在未建立闭合拓扑或双向SDF约束前，不应仅凭可见性从原点集中删点。

## 11. 2026-09-22清理后的可复现状态与下一步

V7–V24、V26–V28均已完成结论提取但不再保留服务器大型训练输出、旧日志和重复诊断包。V4、V6的完整阶段结果继续保留；V25作为V6以后唯一值得保留的阶段版本，在服务器保留car/coffee两场景的筛选源点、最终因子化候选、两份执行日志、指标摘要和代表视觉样本。V18、V22、V25源码归档与校验值继续保留，因此被清理的失败分支仍可由脚本和对应代码记录重建，但旧训练文件本身不可直接恢复。

连续多轮针对car/coffee的点筛选、删点和平滑表明，局部后处理无法同时解决不透明镜面物体的缺边、浮层、法线不连续和倒影模糊。下一轮停止逐场景调参，转为统一的显式点—隐式闭合表面双向约束：几何阶段只使用训练alpha、训练GT法线和多视角第一表面证据，建立窄带有符号场、法线/梯度一致性及闭合表面约束；外观阶段再冻结或弱更新几何，沿用V22-R的粗糙度方向因子化学习镜面反射。该方向与GS-ROR²的显式/隐式几何互导思想相近，后续实现必须在版本文档中继续注明独立实现和差异；不会把Depth Anything相对深度作为绝对几何监督。

## 12. V29：面向不透明镜面物体的点—IMLS双向局部一致性（暂不采纳；见第15节口径勘误）

**2026-09-26勘误：下文保留历史实验数值，但“ball崩溃/隐式场抵消”“确认点法线符号错误”等因果判断没有充分证据，应撤回。ball的轮廓指标使用了错误的全图前景；同时缺少当前代码下零更新的V6对照，不能据此否定整个方法方向。**

V29不再从car或coffee的单一失败形态手工筛点，而是在六场景使用相同规则约束显式有向点与其生成的隐式IMLS场。对每个采样点，首先约束点位于零水平集；随后沿点法线向外/向内各采样一个体素，要求SDF分别为正/负；最后在两个正交切向上约束局部SDF方向导数接近零。只有中心与法线两侧均有真实IMLS核支撑时约束才生效，避免把未覆盖体素的人造正偏移误作自由空间。采样坐标从梯度中分离，但损失仍通过IMLS场反传到点位置、点法线和尺度，降低通过移动采样位置规避约束的风险。

这一约束针对镜面RGB边缘与真实几何边缘易混淆的问题：几何损失不读取RGB、反射贴图或测试视角，只配合训练alpha与训练GT法线；Depth Anything仍只用于最终诊断图。该思路与GS-ROR²的显式GS—隐式SDF互导在动机上相近，但V29直接约束现有IMLS局部场，不引入其网络、训练流程或源码，因此记录为独立实现的相关思路而非复现。

第一版预设法线正侧为正SDF、负侧为负SDF，ball在300步后发生隐式场抵消：`0.935176 / 28.19634 / 0.175639`，轮廓IoU仅`0.50417`，因此立即否决。分析确认源PLY的局部点法线不保证全局内外定向一致，固定符号假设不成立。第二版改为方向无关的“法线两侧必须异号且零交叉足够强”，18项测试通过，并把统一门禁缩短为100步。ball相对V6的结果为`0.953064 / 29.81800 / 0.152680`，PSNR提高约0.509dB、法线平均角误差从`1.253°`降至`0.877°`，但SSIM和LPIPS略退；car为`0.906315 / 20.18870 / 0.085490`，三项均略低于V6且法线平均角误差升至`14.434°`。因此方向无关版仍不能作为六场景统一方法，后续场景被及时停止，所有V29训练输出和日志均已删除，不建立源码版本归档。

V29说明局部点—场约束即使不使用反射RGB，也会受现有点法线质量和开放/多层拓扑限制。下一轮若继续显式—隐式互导，应采用独立闭合表面表示及其自身Eikonal/占据约束，而不是让当前有向点直接决定SDF内外符号；在这之前不再继续调高V29损失或逐场景权重。

## 13. V30：有界稠密隐式残差场（暂不采纳；非独立闭合SDF）

**2026-09-26勘误：V30只有叠加在IMLS上的稠密有界残差，没有独立闭合拓扑、Eikonal约束或低秩分解。下文ball轮廓IoU不可作为有效的几何收益依据；性能下降仍是历史观测，但其原因未由受控实验确认。**

V30在IMLS场之外加入一个独立优化的`48³`连续SDF残差网格，从严格零值初始化并通过三线性插值叠加到提取网格。残差使用`tanh`限制在两个提取体素以内，点位置、点法线、点尺度和反射网络在几何阶段全部冻结；只有训练alpha轮廓、训练GT法线、残差幅值与TV约束更新该连续场。这一设计参考GS-ROR²用独立连续SDF约束显式表示的动机，但没有采用其TensoSDF、互监督网络或源码。实现首先通过21项CPU测试和服务器GPU检查点/反向集成探针。

ball的150步几何门禁为`0.943365 / 27.71127 / 0.159727`，相对V6的轮廓IoU仅从`0.50248`到`0.50424`、法线均值从`1.253°`到`1.247°`，几何收益极小而RGB三项明显下降。为排除“旧反射贴图与新几何失配”，又冻结几何进行1000步同反射头外观恢复，结果为`0.944223 / 27.64050 / 0.158245`，仍未恢复V6。由此否决两体素独立残差场：它对高频镜面方向的扰动大于轮廓收益。4个V30训练/候选目录与全部V30日志已删除，不建立版本归档；代码以默认关闭状态保留作消融。

下一方向转向延迟反射梯度的连续传播：保持V6几何不变，先在表面切空间学习受限微法线，并对训练GT连续区域施加邻域传播/平滑，再让像素级反射误差更新该微法线。该方向与3DGS-DR通过延迟着色把反射梯度传播到邻近法线的动机相近；本项目实现必须继续保持几何法线与反射微法线分离，并明确不能把外观微法线冒充重建GT法线。

## 14. V31：延迟反射微法线传播（未获得实质提升）

V31保持V6真实几何、原反射贴图和其他外观参数全部冻结，只训练已有的切空间反射微法线MLP。像素级RGB/LPIPS误差经延迟反射方向更新微法线；新增的邻域项仅在训练GT法线高度一致、训练alpha内部且远离轮廓的区域，对1像素和4像素尺度的微法线偏移做Smooth-L1传播。导出法线仍使用真实重建法线，微法线仅参与镜面反射方向。该设计明确参考3DGS-DR利用延迟着色将反射梯度传播到相邻法线的动机，但为本项目独立的屏幕空间GT连续域约束，没有复制其Gaussian法线传播实现。

car统一门禁结果为`0.909121 / 20.21310 / 0.084009`；相对V6仅SSIM `+0.00031`、PSNR `+0.0039dB`，LPIPS反而`+0.00024`。改变量过小，不能证明倒影轮廓变清晰，也没有解决缺边；因此V31否决。2个训练/候选目录及日志已删除，不建立版本归档，参数默认关闭保留消融。

V29–V31共同说明：在当前V6点集和反射头上追加局部正则、有限隐式位移或微法线传播，都不足以同时改善几何完整性与镜面倒影。后续不再继续小幅调这些权重；若进入新版本，应更换完整训练基线，使连续SDF从初始化阶段参与几何建立，并与延迟反射头联合但分阶段优化，而不是在已收敛V6表面上做后置修补。

V28不删点，改在法线余弦大于0.98的网格邻接上执行两次弱Taubin连续化，边界顶点权重为0，并使用与外观阶段一致的着色法线平滑。car为`0.901661 / 20.75996 / 0.090437`，coffee为`0.957099 / 27.09191 / 0.110999`；两场景RGB均下降，coffee法线平均角误差仅从10.4517°变为10.4588°，未解决层状表面，V28否决。

正式采纳需要同一版本同时改善几何和RGB；不能用V16的car、V10的coffee和V6的其他场景拼表。法线平滑后的显示图只能是着色诊断，必须同时报告原始几何法线、真实alpha轮廓和固定ROI。最终仍需六场景完整训练、全视角结果、逐场景及等权平均表格；达到目标前不宣称完成。

## 15. V32：不透明前景监督审计与受控几何精修（2026-09-26）

本轮先纠正数据监督，再判断是否需要新的表面表示。不透明镜面重建必须区分真实物体轮廓与镜面反射内容；背景不能作为需要补全的实体表面。

本地和服务器的ball颜色图实际为RGB，前景由同名`*_alpha.png`单独保存；原读取器直接转RGBA，得到全1的alpha，遗漏了单独掩码。r_0训练视角真实前景约占50.316875%，因此此前约0.502的IoU实际上把几乎半幅背景计作缺失物体。car/coffee有原生RGBA，未受这一具体问题影响。此次修改优先保留原生alpha；仅对没有原生alpha且有侧车掩码的图片加载该掩码，不按颜色推断分割。

ball的RGB已经与白背景合成。直接附加alpha再乘一次会错误改变边缘颜色。因此分别保留原始RGB、alpha与原合成背景；换背景用`C_new = C_old + (B_new-B_old)*(1-alpha)`，在白底评估时保持原RGB完全不变。300张ball训练/测试图的alpha=0区域均为254–255，容许独立8位量化的一档偏差。未知背景或尺寸不匹配直接报错，不静默猜测。

这是数据读取/评估正确性修复，不是新的反射网络贡献，也不代表已提高PSNR。修复后先从同一个V6检查点、同一当前CUDA核和提取设置导出零更新对照；再冻结外观，仅用训练前景、GT法线及原有表面约束做100次更新。统一损失规则不按场景挑选模型。GT法线属于额外训练监督，论文必须明确披露，不能作为与纯RGB方法完全等监督的比较。测试GT只用于评估。

本轮不新增第三方算法：继承的粗糙度方向因子化继续注明Ref-GS/Ref-NeRF，历史延迟反射动机注明3DGS-DR；此处sidecar读取与合成修复为独立工程实现。V32暂为审计候选，尚无六场景达标结论。最终采纳时仍需全视角RGB/法线/深度对照；本轮短程门禁暂关闭昂贵深度导出，不把它冒充最终交付。

评估另有需要单独报告的历史口径：`metrics.py`将[0,1]直接输入本地LPIPS-VGG，`BaseNet.forward`没有先转换到[-1,1]；[LPIPS官方说明](https://github.com/richzhang/PerceptualSimilarity)要求[-1,1]输入。因此本轮为维持历史对照先保留原指标计算，但将其视为legacy VGG[0,1]，不能直接和论文标准LPIPS或Alex版本混比，也不能通过换指标口径宣称达到0.08。后续正式论文比较需对全部对照统一重算标准LPIPS，并保留历史列。

同代码零更新ball对照（200个测试视角）为SSIM `0.9537392`、PSNR `29.3052883`、legacy LPIPS `0.1484252`；真实轮廓IoU `0.9958051`、缺失前景 `0.00418749`、法线MAE `0.873259°`。与历史V6的RGB基本一致，但正确掩码显著改变了轮廓统计，不能把这种评估修正算作模型改进。此前V29约`0.877°`也不能再被解释为相对V6的确定性法线改善。

100次几何更新后，ball的200视角结果为SSIM `0.9651230`、PSNR `30.6441326`、legacy LPIPS `0.1248867`，对应相对控制组`+0.011384 / +1.33884dB / -0.023539`；IoU `0.9966898`、缺失前景 `0.00330738`、法线MAE `0.538961°`、P95 `1.181105°`。代表视角00000和00100的法线面片纹理较弱，RGB仍有明显倒影模糊，不能称为全部问题解决。该阶段保留ball最终候选，剩余五场景按相同规则验证中；不是六场景达标结果，LPIPS尚未达到用户目标。

运行环境：Python3.10.21、PyTorch2.4.0+cu118、CUDA11.8、NumPy2.2.6、Pillow12.3.0，GPU为RTX4090，使用imls环境。源码快照`IMLS-Splatting_v32_alpha_audit_20260926_code.tar.gz`保留本轮可复现计算路径，V4/V6/V25归档不变。每场景完成后仅保留最终候选、完整指标、固定代表视角与执行日志；零更新对照的大体积输出和重复训练目录定向清理，可重跑脚本生成但被删除的原文件不可直接恢复。

## 17. V34：训练法线引导的表面连续性门禁

在V32统一候选上增加两个已有但默认关闭的几何约束，仅用训练前景和训练GT法线：GT法线高度一致的相邻像素惩罚预测法线不连续；沿GT连续切平面惩罚相邻可见表面位置的法向位移。这针对coffee托盘的多层起伏，同时避免把镜面倒影纹理误判为形状起伏。其余V32轮廓、点锚和法线损失与学习率一致。先对car/coffee用统一权重`lambda_gt_normal_smooth=0.005`、`lambda_surface_tangent=0.002`做100次更新，并在相同V32检查点基础上评估20个固定视角。若两场景未同时改善法线和RGB，将否决此方向；不能从不同实验挑场景拼最终表。此阶段仍未采用第三方源码，思想上与GS-ROR²强调几何法线约束有关，但没有其独立SDF网络和双向监督。

## 18. V35：固定几何的因子化镜面反射对照设计

如果V34不能消除car/coffee结构问题，后续反射实验继续固定同一套V32几何，不借V34只对某个场景换模型。V35使用项目已有、参考[Ref-GS](https://github.com/YoujiaZhang/Ref-GS)方向与材质因子化的零初始化反射分支，配对比较原反射头与额外分支：同一源检查点、相同500次外观更新、相同训练损失和固定20个测试视角，唯一方法变量是`factorized_reflection`开关与该支路学习率。保持位置、法线、尺度冻结，外观通过表面特征、反射方向、粗糙度方向金字塔及反射材质系数拟合。若倒影轮廓和RGB质量没有足够改善，则不扩大到六场景。该分支已在V22独立实现，本轮没有复制Ref-GS或其他第三方代码；不能把微法线的外观变化当成几何重建完成。

历史指标另以独立工具重算标准输入范围的LPIPS-VGG；该新列与旧口径并存，不覆盖旧结果或借改变指标口径宣称方法进步。已存在的200视角V32与V6图像可用于同口径重算；探针只含20固定视角，不能替代正式评估。
